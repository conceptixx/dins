About DINS

Distributed Intelligent Network Services

Version 1.0.0

DINS is a modular platform for distributed AI-powered services including:

  • Speech-to-Text (STT) with multi-microphone sync
  • Text-to-Speech (TTS) with multi-output routing
  • Local and Cloud LLM integration
  • Docker Swarm cluster management
  • Device discovery and management
